🗔 GTK4 & Libadwaita Design Alignment

1. GNOME / Libadwaita Design Language

  • ▸ Clean Flat Surfaces: Unlike macOS Liquid Glass translucency, GNOME/Libadwaita favors clean, flat dark/light popovers with solid surface hierarchy (#242424 popovers with rgba(255,255,255,0.06) group containers).
  • ▸ Standard Color Palette: Adopts standard Libadwaita accent tokens (GNOME Blue #3584e4, Green #2ec27e, Amber #e5a50a).

2. Navigation & File Manager Integration

  • ▸ Nautilus Integration: Clicking drive rows opens GNOME's native file manager (Nautilus) at the target path (`~/Documents/PhanerosSync`).
  • ▸ AdwListBox & ActionRow ergonomics: Grouping drives inside an AdwPreferencesGroup / GtkListBox container creates a familiar GTK settings pattern.

3. Tauri Linux Tray Implementation

  • ▸ AppIndicator / KStatusNotifierItem: Uses Tauri's Linux tray feature backed by libappindicator3 / ksni crate.
  • ▸ GTK4 Theme Match: Can automatically listen to OS `color-scheme` media queries to sync dark/light mode with GNOME Settings.
