Product Case & UX Refinements

1. Background & Depth Elevation

  • ▸ Continuous Dotted Paper: The background texture extends smoothly through the top header without blocky white header cards.
  • ▸ Card Drop Shadows: Applied multi-layered elevation shadows (`box-shadow: 0 12px 28px -4px rgba(0,0,0,0.06)`) to give floating depth over the dotted canvas.

2. Sync Health & Header Simplification

  • ▸ Green Tick Badge: Replaced redundant 100% dial with a crisp green checkmark (`✓`) when up to date.
  • ▸ Pill Removal: Removed status pill badge from top header to eliminate visual redundancy.
  • ▸ Header Controls: Moved app launcher (`↗`) and preferences (`⚙`) to top-right header icons. Removed bottom action bar completely.

3. Per-Drive Card UX (Folder Launcher)

  • ▸ Removed drive tab pills. Each configured drive gets a dedicated card.
  • ▸ Each card includes a mini ring gauge (`42% used`), storage capacity text, and real-time status ("Last synced 2m ago").
  • ▸ Clicking any drive card opens its local path in Finder (`~/Documents/PhanerosSync`). Hovering reveals a prompt.

4. The Product Case for Recent Activity

Should Recent Activity be in the Tray UI?

  • ▸ Arguments FOR keeping it: Answers "Which exact file just saved?". Provides immediate audit reassurance after saving in an editor without launching Finder.
  • ▸ Arguments FOR removing it: Drive cards already show overall sync health + "Last synced 2m ago". Removing recent activity reduces total tray height by 35%.
  • ▸ Recommendation: Use the "Toggle Recent Activity" button in the header toolbar above to evaluate both compact (Drive-only) and complete (Drive + Recent Activity) variations!
