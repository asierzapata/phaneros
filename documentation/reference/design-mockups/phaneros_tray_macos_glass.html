 macOS Native Glass Vision — Architectural Comparison

1. Material & Surface Physics

  • ▸ V3 Dotted Paper (Web): Uses a fixed radial background gradient pattern inside an opaque HTML card. It looks like a custom web document inside a popover box.
  • ▸ Native Glass (macOS): Uses NSVisualEffectView / SwiftUI .ultraThinMaterial. The tray popover dynamically samples colors & light from whatever desktop wallpaper or app window is behind it!

2. Typography & System Coherence

  • ▸ V3 (Merriweather Serif): Merriweather gives a warm editorial book feel, but feels slightly foreign in a macOS system menu popover.
  • ▸ Native Glass (SF Pro / SF Mono): Uses -apple-system fonts with optical kerning, exact tabbed figures (tabular-nums for file sizes), and native Apple font rendering.

3. Visual Hierarchy & Card Elevation

  • ▸ V3 Shadow Heavy: Uses deep black drop shadows (`0 12px 28px rgba(0,0,0,0.06)`).
  • ▸ Native Glass Specular Rims: Replaces heavy shadows with subtle 0.5px glass highlight borders (specular reflections on top edges) and native macOS horizontal progress capsules (like iCloud / Time Machine).

4. Structural Recommendations

  • ▸ Keep Per-Drive Finder Launchers: Clicking any drive glass tile opening Finder is an outstanding UX pattern.
  • ▸ Default Collapsible Activity Stream: In a native macOS tray, saving vertical popover space is crucial. Having recent activity collapsed by default (or expanding on hover) keeps the window lean (~280px high).
